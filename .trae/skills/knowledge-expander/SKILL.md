# 知识库扩充技能

## 用途

从可信的科学来源（顶刊、权威机构）搜集有价值的知识条目，经过交叉验证后写入知识库，确保每一条都真实可靠，并附带启发批判性思考的问题。

## 触发场景

- 用户说"再加点知识"、"扩充知识库"、"多找点冷知识"
- 用户要求从期刊/论文/权威来源获取更多内容
- 知识库条目数不足，需要批量补充

## 方法论：三源两查一溯源

### 1. 来源分级（只采 P0/P1）

| 等级 | 类型 | 示例 |
|------|------|------|
| **P0（原始文献）** | 顶刊论文、权威机构报告 | Nature、Science、Cell、PNAS、NEJM、Lancet、Nature 子刊、NASA/WHO/NIH 官方 |
| **P1（权威二手）** | 顶校新闻稿、专业科学媒体 | 哈佛/MIT/剑桥/洛克菲勒等大学新闻稿、ScienceDaily、Phys.org、科学网 |
| P2（仅作线索） | 主流媒体、科技博客 | 不能直接作为来源，必须追溯到 P0/P1 |
| P3（不可用） | 自媒体、论坛、问答 | 完全排除 |

### 2. 交叉验证规则

- **核心事实**：至少 2 个独立来源印证（互相引用不算独立）
- **数字/统计**：必须追溯到原始论文或官方报告
- **争议内容**：明确标注"存在争议"或"尚在研究中"，不选边站
- **时效性**：优先近 1-2 年内的研究

### 3. 防幻觉检查清单

- [ ] 能否找到原始论文 DOI 或机构官方页面？
- [ ] 关键数据（百分比、年份、数量）是否与原始来源一致？
- [ ] 标题是否有标题党倾向？是否还原了研究的真实意义？
- [ ] 是否区分了"相关性"和"因果性"？
- [ ] 是否区分了"初步发现"和"定论"？

## 知识条目格式

写入 `knowledge.js` 中的 `knowledgeBase` 数组，每个条目结构如下：

```javascript
{
  id: <自增数字>,
  category: "<分类名，如：物理学/医学/心理学>",
  title: "<简洁有力的中文标题，20字以内>",
  content: "<150-200 字通俗解释。包含：是什么、怎么发现的、为什么重要。避免术语堆砌>",
  type: "<cold 或 hot>",     // cold=冷门/小众  hot=热门/大众都应该知道
  difficulty: <1-5>,         // 1=常识 5=专业前沿
  source: {
    name: "<来源名，如：Nature - 论文标题>",
    url: "<原始来源 URL>",
    reliability: "高"         // P0/P1 来源标"高"
  },
  questions: [
    "<第 1 个批判性思考问题>",
    "<第 2 个批判性思考问题>",
    "<第 3 个批判性思考问题>"
  ]
}
```

### 内容写作原则

1. **通俗化**：用大白话解释，必要时给类比，但不能牺牲准确性
2. **有画面感**：让读者能"想象"出来是什么
3. **留悬念**：结尾自然引出思考问题，而不是说教
4. **不夸大**：避免"史上最""完全颠覆""震惊"等词
5. **诚实标注不确定性**：如"尚在研究中""初步结果显示"

### 批判性思考问题设计

每个条目配 2-3 个问题，遵循以下方向：

- **反常识**：挑战读者的直觉或默认假设
- **延伸推理**：如果这个发现是对的，那还能推导出什么？
- **方法论**：这个结论是怎么得出来的？方法是否可靠？
- **伦理/社会影响**：对现实世界有什么影响？
- **对比/类比**：和已知的什么现象相似或不同？

避免"你怎么看？""你觉得呢？"这类空泛问题。

## 工作流程

1. **规划**：确定本次扩充的领域和数量（建议每次 20-30 条，分 2-3 个领域）
2. **搜集**：用 Explore 子代理并行搜集不同领域的知识（最多 3 个并发）
3. **筛选**：去掉重复、过于相似、来源不可靠的条目
4. **写作**：按格式整理，确保语言通俗、问题有启发性
5. **溯源**：每条知识附上原始来源 URL 和名称
6. **写入**：追加到 `knowledge.js` 的 `knowledgeBase` 数组末尾，id 自增
7. **校验**：用 `node` 检查 JS 语法和条目数量
8. **部署**：git commit + push，GitHub Pages 自动更新

## 领域覆盖建议

优先补充现有条目较少的领域：
- 历史、艺术史、文学、语言学
- 数学、计算机科学
- 经济学、人类学、考古学

冷热搭配：热知识（大众应该知道的）和冷知识（小众但有趣）比例约 1:2。
