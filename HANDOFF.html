01目标

用户原始诉求，按提出顺序：

  1. 每日随机推荐各领域知识，无偏好设置、无智能推荐。
  2. 每日通知，自动随机推荐。
  3. 知识有可靠来源、正确、不糊弄。
  4. 通过设置或提问模式锻炼批判性思维。
  5. 持续扩充知识库，冷热均可，条目不能太少。
  6. 增加 AI 接口，可针对知识提问。
  7. 公开网站，可用 Git 部署。
  8. 杂志感视觉、个性化字体、主色鲜明有记忆点。
  9. （曾讨论）上架 iOS，后选择先做公开网站。

06否决 / 放弃的方案及原因

方案处理原因可核对证据
Vercel + Python Serverless 代理 放弃作为主部署 前端可直连 Pollinations（实测 200），静态托管更简单、免费，代理多一层故障点 api/ask.py、vercel.json 仍在；前端无 /api/ask 调用
本地 Python 代理承载线上流量 放弃 同上；server.py 仅保留本地开发 前端调用路径不经过 /api/ask
iOS 原生打包（Capacitor 等） 未执行 用户选择先做公开网站；需 Apple Developer 账号、Xcode 与审核，成本周期未核实 仓库无 iOS 工程文件
PWA（manifest + SW） 未执行 用户未选择；当时优先公开网站与内容 无 manifest、无 service worker
「否决」是当时的选择，不代表技术上行不通。Vercel / PWA / iOS 仍可作为后续路线。
